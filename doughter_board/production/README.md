# Заказ на JLCPCB — дочерняя плата питания UHK BLE adapter

Файлы (пересобрать: OutJob `../daughter_board_JLC.OutJob` в Altium → `python ../make_jlc.py`):

| Файл | Что |
|---|---|
| `daughter_board_gerber.zip` | Gerber RS-274X (GTL/GBL/GTO/GBO/GTP/GBP/GTS/GBS, контур GM1) + Excellon (PTH круглые, PTH пазы, NPTH) |
| `daughter_board_BOM_JLC.csv` | BOM для сборки (коды LCSC) |
| `daughter_board_CPL_JLC.csv` | координаты для сборки (верх, мм от нижнего левого угла платы) |

## Параметры платы

- Слоёв: **2**, FR-4, толщина **1.6 мм**, размер **17.4 × 45 мм**
- Медь 1 oz, маска любая, покрытие HASL lead-free (или ENIG)
- Минимум по проекту: дорожка 0.2 мм, зазор 0.15 мм, переходное 0.3/0.6 мм — стандартные
  возможности JLC, без доплат
- Пазы экрана USB-C (0.6 мм, длина 1.2/1.7 мм) — в отдельном файле `SlotHoles-Plated`;
  если JLC спросит про пазы — это они, металлизированные
- Remove Order Number: по желанию (Specify a location — места на плате мало)

## Сборка (PCBA, только верх)

10 компонентов, все SMD на верхней стороне (сторона компонентов = сторона, которая лежит на
корпусе LilyGo):

| Обозн. | LCSC | Что |
|---|---|---|
| J1 | C319148 | XKB U262-161N-4BVC11, USB-C 16P (extended; замена GCT USB4105-GF-A — того нет на складе JLC) |
| F1 | C89647 | Bourns MF-MSMF110-2, PTC 1.1 A (extended) |
| R1, R2 | C23186 | 5.1k 1 % 0603 (basic) |
| R3, R4 | C22809 | 15k 1 % 0603 (basic) |
| C1 | C96123 | 47 µF 10 V X5R 1206 |
| C2 | C14663 | 100 nF X7R 0603 (basic) |
| C3 | C110050 | KEMET T491B106K016AT, тантал B (extended) |
| C4 | C123716 | KEMET T491A105K025AT, тантал A (extended) |

Поправки CPL под футпринты EasyEDA уже внесены (`make_jlc.py`): J1 — начало координат
футпринта JLC на 1.386 мм ближе к ряду падов (сверено по ножкам экрана и пегам),
C3 — +180° (у EasyEDA «+» с другой стороны).
**В превью JLC проверить:** полоска «+» танталов C3/C4 должна смотреть на шину +5V
(левый край платы, к краю), USB-C — гнездом к верхнему краю.

H1/H2 (штыри 1×4, 2.54 мм) не в сборке — паять руками: вставить со стороны компонентов,
пропаять, снять пластиковую планку, обрезать штыри до 2.3 мм (сторона компонентов) и
≤ 0.8 мм (обратная сторона). Подробнее и корпус: `../shell/PRINT.md`.

## Проверено

- DRC Altium: 0 нарушений; ERC: 0
- Контур GM1: 17.40 × 45.00 мм; сверловка: 11 × Ø0.3 (переходные), 8 × Ø1.0 (штыри),
  4 паза 0.6 мм (экран USB-C), 2 × Ø0.65 NPTH
- Все 34 SMD-пада в гербере пасты совпадают с моделью (`pcb_layout.py`) — начало
  координат гербера = начало координат CPL
